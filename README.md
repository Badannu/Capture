# Capture

Windows 10/11 上的轻量截图程序。热键唤起后整屏变暗（约 60% 黑），顶部正中是一条贴近系统截图工具的胶囊条。

（v1.5.0 起产品名、exe 文件名、程序集名统一为 Capture；源码目录与命名空间仍是 `CaptureDemo`，两者本来解耦。老用户升级：旧 `%AppData%\CaptureDemo\settings.json` 会在首次启动时自动迁移到 `%AppData%\Capture\settings.json`，旧的开机自启项（`Run\CaptureDemo`）会被自动清掉并按你的设置重写成 `Run\Capture`。）

和 Windows 截图条的对应关系：

- 位置与比例：贴在当前屏幕工作区顶部正中，高度 46 像素（另加很浅的阴影），按钮约 40 像素、图标约 26 像素，两端是全圆角。底是近黑的半透明，不是一排大按钮。之前的 36 像素偏小，和系统截图条放在一起看差距明显，所以整条放大了一档；标注条仍是紧凑的 36 像素（它有 21 个格子）。
- 我们只做截图，所以六种模式都直接排在胶囊上，不再收进下拉菜单。从左到右：全屏、矩形、窗口、长截图、元素截图、任意形状。**当前模式是一块填充的蓝色圆角底板加白图标**，不是一条细下划线——因为选中之后胶囊不会消失，得一直能看出来选的是哪个。
- 右侧是较淡的设置齿轮，再是关闭。悬停提示出现在图标下方；长截图和元素截图会带上各自的热键，关闭写的是「关闭(Esc)」。
- 参考图里系统把模式收进菜单，是因为它还要放录像和提取文字。那些按钮这里没有。
- 选区确定之后，标注工具是同一条胶囊语言：长截图、选择、画笔、直线、箭头、矩形、圆角矩形、椭圆、圆、高亮、马赛克、颜色、粗细、撤销、保存、放弃。当前工具下面有蓝线。

六种模式（切换只改变胶囊上的高亮，胶囊本身一直留着，直到选区框定）：

1. **全屏** — 截取鼠标所在的那一块显示器（含任务栏，不是多屏拼在一起，也不是去掉任务栏的工作区）。
2. **矩形** — 拖一个矩形，洞外变暗、洞内保持原亮度。
3. **窗口** — 悬停高亮顶层窗口，单击选中。
4. **任意多边形** — 按住画出闭合路径，路径外在 PNG 里是透明的。
5. **长截图** — 先拖出要拼接的区域，松手后才进入滚动拼接。选区框在滚动过程中保持你松开鼠标时的矩形。
6. **元素截图** — 在当前覆盖层里悬停高亮 UI Automation 控件，单击截取，滚轮切换父子层级。不再另开一层选择界面。

全屏、矩形、窗口、任意形状选好之后，选区下方出现标注条（全屏则贴在画面底部），从左到右分五组：**长截图** ｜ 选择、画笔、直线、箭头 ｜ 矩形、圆角矩形、椭圆、圆 ｜ 高亮、马赛克 ｜ 颜色、粗细、撤销、**✓ 保存**、**✗ 放弃**。只有 ✓ 会写 PNG；✗ 和 Esc 都不保存。标注条上的长截图用当前选区直接开滚（任意形状用外接矩形）。

颜色和粗细点开后，**小组件不会自己消失**：选完一个还能接着换，直到你点别处（或按 Esc，第一次只关小组件）才收起。

设置窗口按「快捷键 / 保存 / 剪贴板 / 长截图 / 常规」分块，保存在 `%AppData%\Capture\settings.json`：唤醒热键、元素热键、长截图热键、剪贴板热键、保存目录、文件名模板、✓ 时是否复制剪贴板、是否记录剪贴板、保留条数、长截图速度和采样间隔、外观、开机自启、**关闭窗口后常驻托盘**。

窗口高度是固定的，内容比窗口长时右侧出现自绘滚动条（滚轮、拖动滑块、点击空白轨道都能滚，Tab 切到看不见的控件会自动滚过去）。**版本号在滚动区最末尾**，滚到底才能看到——这样以后加设置项只会往下长，不会把窗口撑高。版本号下面是**联系方式**：一行 `Tel: Guth_Lee` / `Email: guthirelee@gmail.com`，两段中间用分号隔开，各自前面一个线图标（纸飞机、信封），与版本号各占一行、各自居中，没有小标题；图标与文字同色同字号，鼠标压在某一段上才变蓝，点一下把该段的值复制到剪贴板，右侧闪一下「已复制」。

热键被别的软件占用、或两行写成同一个组合键时，**该行右侧出现红色圆圈感叹号**，点一下弹出说明（哪个组合键、和谁撞了、大概率是哪个程序的哪个功能）。Windows 不会告诉程序"谁占用了热键"，所以占用者是按常见默认快捷键 + 正在运行的进程推断的，措辞里写的是"大概率"。主窗口底部那一行提示只在真的有问题时才有内容。

版本号只有一处定义：仓库根目录 `Directory.Build.props` 里的 `<Version>`。改那一个数字，exe 文件属性、设置页页脚、`Capture.exe --version` 三处同时跟着变。

程序启动后停在托盘，不占任务栏。左键图标打开主窗口。右键菜单：打开主窗口、截图、长截图、元素截图、剪贴板、设置、退出。主窗口的关闭按钮默认只是回到托盘；在设置里关掉「关闭窗口后常驻托盘」之后，关窗口就是退出（热键会一并释放，方便让给别的软件）。只有「退出」会卸掉热键并结束进程。不做 OCR，也不上传。

## 环境

- Windows 10（1809 及以上）或 Windows 11，**仅 64 位**
- 安装版：不需要任何运行时，下载 setup.exe 双击安装（默认按当前用户装，不弹 UAC）
- 便携版：不需要任何运行时，解压双击即用
- 在线版（框架依赖，默认不发布）：安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)（x64）
- 自行编译：安装 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

不需要 VC++ 运行库、WebView2 或额外字体，也不联网、不装服务。完整的依赖清单（每个 dll 干什么、程序会往哪写、三个包怎么对比）见 [PACKAGING.md](PACKAGING.md)。

程序声明了 Per-Monitor V2 DPI。高分屏上 UIA 边界、鼠标坐标和 `CopyFromScreen` 使用同一套物理像素。

## 运行

在仓库根目录打开 PowerShell。

```powershell
powershell -ExecutionPolicy Bypass -File .\run-element.ps1
powershell -ExecutionPolicy Bypass -File .\run-long.ps1
```

不带参数会打开主窗口。点「开始截图」或按唤醒热键进入顶部工具栏：

```powershell
dotnet run --project src/CaptureDemo/CaptureDemo.csproj
dotnet run --project src/CaptureDemo/CaptureDemo.csproj -- --snip
dotnet run --project src/CaptureDemo/CaptureDemo.csproj -- --element
dotnet run --project src/CaptureDemo/CaptureDemo.csproj -- --long
```

默认全局热键（主窗口进程还在时，可在「设置」里改）：

- `Ctrl+Alt+S` 唤起截图条（矩形模式）
- `Ctrl+Alt+E` 唤起截图条，并预先选中「元素截图」
- `Ctrl+Alt+L` 唤起截图条，并预先选中「长截图」
- `Ctrl+Alt+V` 打开剪贴板历史
- `Esc` 取消当前截图；长截图里则停止并保存已经拼好的部分

三个截图热键现在走的是同一个入口：都是先弹出胶囊条、把对应模式点亮，再由你框定区域。托盘菜单和主窗口上的「长截图」「元素截图」按钮也一样。

查版本（也可以给 `publish\Capture.exe` 传 `--version`）：

```powershell
dotnet run --project src/CaptureDemo/CaptureDemo.csproj -- --version
```

## 基本截图怎么用

1. 按 `Ctrl+Alt+S`（或托盘右键「截图」、主窗口「开始截图」）。桌面变暗，顶部正中出现胶囊条，六种模式都是独立图标，当前模式是一块蓝色底板。
2. 矩形：按住左键拖动，松开后在选区下面标注。窗口：移到窗口上单击。任意形状：按住画出路径。全屏：点图标后直接进入标注，画面是鼠标所在显示器的整屏。
3. 画笔按住自由画；直线、箭头、矩形、圆角矩形、椭圆、圆都是拖出对角即定形（圆强制正圆）。高亮是半透明色块，马赛克把拖出的矩形打成像素块。
4. **颜色**点开后是八色预设（红橙黄绿蓝紫白黑），**粗细**是四档。不弹色盘，选完即用，而且小组件会一直开着——可以连着换几个，点画布或按 Esc 才收起；改颜色或粗细会同时作用于当前选中的对象。
5. **选择**工具用来整理已有标注：单击选中，框外拖动＝移动，八个手柄＝自由缩放（线宽不变）。选中后按撤销＝删除这一条。
6. ✓ 按设置里的目录和文件名模板保存 PNG。默认同时复制到剪贴板，可以在设置里关掉。✗ 丢掉这张图。
7. 标注条最左边的「长截图」用这块选区进入滚动拼接，不保存当前涂鸦。

## 元素截图怎么用

1. 打开记事本、资源管理器或设置。
2. 按 `Ctrl+Alt+E`，或点截图条上的「元素截图」。主窗口会先藏起来，胶囊条留在原位，「元素截图」那块底板是亮的。
3. 移动鼠标。能读到辅助功能树的控件会以「原亮度的洞」标出来，并写上类型和名称。洞的外面是暗的。
4. 滚轮向上选父级（范围变大），向下回到子级。
5. 左键截取当前高亮。图片写入剪贴板，并保存到下面的目录。截完胶囊条才消失。
6. 若是自绘、游戏、或没有控件树的区域，黄字会提示换一处；想按矩形截就切到「矩形」模式。
7. `Esc` 取消。

覆盖层是点击穿透的，悬停仍会作用到下面的窗口；左键和滚轮在选择期间被本程序吃掉，避免把按钮点下去或把页面滚走。蒙版用分层窗口的逐像素透明做成：洞的 alpha 是 0，所以选区不会被压暗。截图前会先把蒙版藏起来。

## 长截图怎么用

1. 打开一篇比较长的记事本、设置页或网页。
2. 按 `Ctrl+Alt+L`（或点截图条上的「长截图」）。胶囊条不会消失，只是「长截图」亮起来；拖一个矩形。选区是亮的，外面是暗的。**尽量只框可滚动的内容**，不要框住固定的标题栏、工具栏、底栏或侧栏。
3. 松开鼠标。**蒙版不撤，选区框也不再变形。** 你松开时的那个矩形一直是一块原亮度的洞，外面保持约 60% 的暗；洞里就是正在滚动的画面。高度和帧数写在洞外面的暗区上（整屏几乎没有暗边时，会贴在最上方一条）。不再另开小预览窗。
4. 程序把滚轮打到「真正在动」的那一块，并尽量避开任务栏。**屏幕上的亮洞始终是你拖的矩形**，不会收成正文、两条亮带或贴在顶上的窄条。自动滚动在整个捕获期间不停：默认速度 1 大约每秒 1000 个滚轮单位（原来「3 格 / 180 毫秒」的一半），大约每 4 毫秒送出几个单位，单次不超过 40（一整格是 120）。抓屏和拼接的时候滚轮也不停，所以画面是连续往下走，而不是每截一帧停一下。采样间隔默认 120 毫秒，这一段里滚过的距离仍大约是从前的 1 格，帧与帧重叠够拼接。
5. **滚动鼠标滚轮会立刻改为手动，并且之后不会再自动滚。** 注入立刻停。页面跟着你的滚轮走。滚轮停一下（默认约 120 毫秒）就抓下一帧。
6. 若选区几乎是整屏（Word 最大化再带上任务栏这种），程序会比较前两帧，**只在内部**改用真正在滚动的那一块来拼接，功能区和任务栏尽量不进长图。屏幕上的洞保持你拖的整块。固定顶栏和底栏若仍留在抓取范围内，对齐时会尽量只保留一份，不在长图里反复出现。
7. 正文不再变化（连续两帧都一样）、连续三帧都拼不上新内容、高度达到 20000 像素、帧数达到 150，或按 `Esc`，都会停。还没滚起来之前，不会因为「整屏平均起来几乎没变」就停（白页和功能区会把平均值稀释掉）。`Esc` 仍会保存已经拼好的部分。

8. 主窗口上可以改「自动滚动速度」（1–10，默认 1，即半速丝滑）和「采样间隔」（默认 120 毫秒，最少 40）。速度 2 接近原来的整速；再高时页面走得快，拼接更容易接不住。页面懒加载时把采样间隔加大。浏览器和较新的 Word 会按像素跟着这些小步走。老式编辑框通常把单位攒满 120 才滚一次（系统默认大约三行），所以在记事本里仍可能一行组一跳。

固定条的判断在 `StickyDetectOptions`：一行的平均通道差不超过 2.5 就算没动；短于 3 行的忽略；单边最多占区域高度的 30%。**状态栏这类「整条不动、但里面有几个数字在变」的栏也能认出来**：只要一行的差异全挤在一条不超过 25% 宽的窄列里（页码、字数、缩放百分比就是这种），这一行仍按没动算，底边最多因此再向内多吃 64 行。所以框选了 Word 底部那条「第 3 页 / 共 67 页 · 120%」，它会在长图里只出现一次，而不是每帧贴一条、也不再把捕获提前结束。另外默认会看区域**底部 12%**（`BottomIgnoreFraction`，顶部默认 0），但这一刀最多再扩大到 96 像素，避免在整屏上把正文边距也裁掉。只有这一带确实几乎没动时才排除。第一次认出来的边不会在后面的帧里变短，也不会越认越大。

位移搜索默认在「上一帧滚过的距离」附近找（`SearchWindowFactor`，默认 2.2 倍以内）：白页底部那一截在任何位置都对得上，全局搜索容易得出「整帧都见过」的结论，于是新增 0 行、捕获停住。窗口内找不到好匹配时才回退全局。

整屏选区的蒙版靠 `WDA_EXCLUDEFROMCAPTURE` 排除在截图之外。洞是透明的，截到的是洞下面的真实画面。极老的系统若忽略这个标志，暗角可能进 PNG；Windows 10 2004 及以后一般不会。

## 剪贴板历史怎么用

1. 托盘右键「剪贴板」，或按 `Ctrl+Alt+V`。主窗口的「剪贴板」条目也会打开同一块面板。
2. 面板贴在鼠标所在显示器的中间偏右，宽度固定，一次显示最近 8 条，超出用滚轮翻。表头写着当前条数，页脚左边是「清空历史」，`Esc` 关闭。
3. 双击一条：文本会重新复制到剪贴板；图片和文件用系统默认程序打开（图片进「照片」，文件进资源管理器或对应程序）。
4. 光标停在某条上按右键，二级菜单：
   - **打开 / 复制** — 文本是「复制」，图片和文件是「打开」，也就是双击的默认动作。
   - **复制到剪贴板** — 图片或文件才出现。
   - **复制路径** — 文件才出现。
   - **另存为…** — 图片另存到你选的位置。
   - **在文件夹中显示** — 在资源管理器里选中这条记录对应的文件。
   - **置顶 / 取消置顶** — 置顶的条目永远排在前面，不会被新记录挤下去。
   - **删除**、**清空历史** — 前者只删这一条，后者保留置顶项。
5. 记录开关和保留条数（5–30，默认 12）在设置的「剪贴板」分块里。关掉开关就只是不记录，已有历史仍在。

排重按内容指纹做：同样的图片或文本再复制一次，不会多出一条，而是把原来那条移到最前并刷新时间。容量满了先挤掉最旧的未置顶项。程序自己写剪贴板（✓ 保存时的「复制到剪贴板」）不会反过来生成新记录。

记录放在 `%AppData%\Capture\clipboard\`：图片存成 PNG（长边最多 4096 像素）加一张正方形缩略图，另有一份 `index.json`。**这些文件是明文**，删掉整个目录等于清空历史。

## 输出

`%USERPROFILE%\Pictures\Capture\`

文件名类似 `element-20261027-153045-123.png`、`long-20261027-153112-456.png`。主窗口底部可以打开这个目录。

## 已知限制

- 没有辅助功能树的界面（多数游戏、自绘画布、部分 Electron 内部控件）高亮不到具体控件，只能拖矩形。浏览器里通常只能看到浏览器暴露给 UIA 的节点，不是完整 DOM。
- 截到的是屏幕上的可见像素。被别的窗口挡住的部分会带上挡在前面的内容。
- 长截图假定选区里的内容会整体向上平移。屏幕上的选区框始终是你松开鼠标时的矩形。整屏选中时，拼接会改用里面实际滚动的那一块，但亮洞不变。若整页几乎都不动（滚轮没打到文档上），试过几个落点后仍会停，并提示高度没有增长。固定顶栏/底栏若留在抓取范围内，程序会尽量只保留一份（状态栏里变化的页码、字数、缩放百分比也算「不动」）；但整条都在动画（跑马灯、视频进度、自动轮播）或超过区域高度约 30% 的固定条仍可能重复，遇到这种就别把它框进来。重复的列表、视频、闪烁光标也会让对齐不稳。
- 自动滚动只在你还没碰滚轮时进行。它是一串小于一格的滚轮事件，抓屏时也不暂停。一旦滚动滚轮，本次捕获保持手动，不会自己再滚。想继续就再滚；`Esc` 结束并保存。只认满格滚轮的老控件仍会一次滚动多行。
- 只做向下滚。不发送横向滚轮，也不发 `Page Down`。不响应滚轮的程序拼出来仍是一屏，结果提示里会说明高度没有增长。
- 全屏只截鼠标下面那一台显示器，包含任务栏。要多屏各自截一次。
- 任意形状保存的 PNG 在路径外是透明的。从标注条进入长截图时，用的是这个形状的外接矩形，不是镂空路径。
- 标注画在已经截下的位图上，✓ 之前不会写文件。工具条本身用 `WDA_EXCLUDEFROMCAPTURE` 排除，不会进图。
- 标注层只覆盖选区，鼠标移动时只重画笔尖划过的那一小块矩形，并按脏区提交。1080p 选区下画笔每帧约 0.25 ms、拖拽图形约 0.9 ms；同一张图走整幅重合成是 8–25 ms（视构建与选区大小），这也是之前拖动发涩的原因。可用 Debug 构建的 `Capture.exe --bench <报告.txt>` 复测（该开关只在 Debug 编进去，Release 包里没有），它会顺带写一张 `layer-shot.png` 作为标注层实机证据。
- 选择工具目前只做整条移动和整体缩放，不支持旋转、多选、层级调整（置顶/置底），也不支持对单条标注改色后保持其它属性不变。
- 多显示器混用不同 DPI 时，极少数跨屏窗口的框可能偏几个像素。
- 高度上限 20000 像素，帧数上限 150。超出后保存已经拼好的部分。
- 剪贴板历史只认文本、图片和资源管理器复制的文件三项。富文本（HTML/RTF）只按纯文本记录；从 Office 复制的内容可能变成一段纯文字。历史上限 30 条，图片按 PNG 落盘，明文保存，不加密。
- **索引读不出来的那一轮，新复制的条目不落盘**：`clipboard\index.json` 和它的备份 `index.bak.json`
  都读不出来（被别的程序独占、或内容损坏）时，程序进入只读历史模式——这一轮新复制的东西只在
  内存里可见，退出后不保留，也不做孤儿清扫；重启后若备份能读回来，历史和写入都会恢复。这条路径
  很少走到，真走到时宁可不写，也不能用空数据覆盖掉一份本来完好的索引。
- **安装版和便携版各有各的一套**：两者的单实例互斥体、唤醒消息和设置目录都按运行形态分开，
  所以能同时跑，互不干扰（各自一份设置和历史）。但它们**共用同一组全局热键**——后启动的那份会
  报「热键被占用」，属预期行为。
- 进程空闲时不加载 OCR，也不保持捕获会话。元素模式结束时会释放 UI Automation 对象。

## 建议的手工验收

在 Windows 11 上：

1. 打开记事本，输入几行字。元素模式悬停「文件」菜单或窗口按钮，左键保存，确认 PNG 只包含该控件，并且剪贴板能粘贴。
2. 在记事本或 Word 里贴一段超过一屏的文字。只框文字时，PNG 应比一屏更高。再试一次几乎整屏的选区（含功能区或任务栏）：滚动过程中洞外应保持变暗，**亮洞的形状一直是松开时的那个矩形**，不要收成窄条或两块。画面应连续往下走，而不是每截一帧停一下。得到的图也应高于一屏。滚动滚轮后自动滚动应停住，状态文字改为「手动」。
2.1 打开一篇多页 Word 文档，**把底部那条「第 N 页 / 共 M 页 · 字数 · 缩放百分比」也框进选区**再滚。长图应能一直滚到文档末尾，不会几帧就停；状态栏在长图里只出现一次，且是完整的一条。滚过几页后页码会变，变化不能让它提前结束。
3. 按 `Ctrl+Alt+S`。顶部应是一条矮的圆角深色条，六个模式图标并排，当前项下有蓝线。悬停关闭应出现「关闭(Esc)」。矩形拖完后，选区下面是同一风格的标注条。✗ 不应产生文件。✓ 应在设置的目录里出现 PNG。托盘右键「设置」只打开设置窗口，不把主窗口拉出来。关掉主窗口后进程还在托盘里；菜单「退出」才会结束。改一次热键和目录，退出再开，设置还在。
4. 对桌面空白处做元素模式，应出现拖矩形的提示；拖一块后能保存。
5. 长截图按 `Esc`，应留下已经拼好的那一段，而不是丢弃。
6. 复制一张图片、一段文字、几个文件，再按 `Ctrl+Alt+V`。面板里应出现三条，最新的在上面，图片那条左侧是缩略图。双击文字应按回剪贴板；双击图片应用「照片」打开。在某条上右键，菜单里首项是「复制」或「打开」，分隔线之后再是置顶/删除/清空。置顶一条，再复制几条新内容，置顶项应仍在最上面。关掉记录开关后复制东西，条数不应增加。
