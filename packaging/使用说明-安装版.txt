Capture 安装版使用说明
======================

（这份说明是给 Release 页面用的，安装包本身不带这个文件。）


装到哪里
--------
默认：C:\Users\<你的用户名>\AppData\Local\Programs\Capture
      —— 也就是「为当前用户安装」时的默认位置，不需要管理员权限。

安装器启动时会问「为所有用户安装」还是「仅为我安装」：
  - 仅为我安装（默认）：装到当前用户目录，不需要管理员权限，其他账户看不到。
  - 为所有用户安装：需要管理员确认（UAC），装到 C:\Program Files\Capture。


怎么改安装位置
--------------
安装向导第二页就是「选择目标位置」。改掉路径后点「下一步」即可，程序本身不依赖
安装位置，装到 D:\Tools\Capture 这种自定义目录完全没问题。

之前用过便携版的话，建议先关掉便携版再装，避免两个都在托盘里同时响应热键。


装完之后
--------
- 开始菜单会出现「Capture」；安装时勾了「创建桌面快捷方式」的话桌面上也有一个。
- 装完可以直接勾「运行 Capture」，程序启动后停在托盘，不占任务栏。
- 设置与剪贴板历史存在 %AppData%\Capture\（settings.json + clipboard\）。
- 截图默认存到 图片\Capture，可以在设置里改。
- 开机自动启动由程序内的开关控制（设置 → 通用），安装器不写注册表自启项。


怎么卸载
--------
两种方式都可以：
  1. 设置 → 应用 → 已安装的应用 → Capture → 卸载
  2. 开始菜单里「Capture」文件夹旁边的卸载快捷方式，或
     「C:\Users\<用户名>\AppData\Local\Programs\Capture\unins000.exe」

卸载时会自动做两件事：
  - 删掉程序目录、开始菜单和桌面快捷方式、以及 HKCU\...\Run 下的 Capture 自启项；
  - 然后弹一个询问框：「是否同时删除设置与剪贴板历史（%AppData%\Capture）？」
    默认按钮是「否」——保留设置，以后重装还能接着用。
    选「是」才会真的删掉那个目录，删了不可恢复（截图原图存在 图片\Capture，不在里面）。

便携版的数据不在这两个位置，卸载安装版不会动它。


升级
----
直接运行新版本的安装器覆盖安装即可：AppId 相同，安装器认得这是同一个产品，
会原地替换并保留设置。装的时候如果 Capture 正在运行，安装器会提示你先关闭它，
不会强行结束进程。


环境要求
--------
Windows 10 1809（build 17763）以上 或 Windows 11，64 位。
不需要预装 .NET 运行时——安装包里带的是自包含版本。
